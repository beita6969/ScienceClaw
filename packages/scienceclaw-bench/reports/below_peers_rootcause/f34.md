# FoR34 ogbg-molhiv — 现成的分子预训练表示(CheMeleon)能否超过默认的 RDKit 指纹 + 树模型

标注: [实测] = 实际跑出(脚本与日志在 `scripts/f34/`), [估计] = 判断, 未测。
口径: 只评"开工具"版本; 只用别人训练好的权重, 不自己训练(用户 2026-10-01 的要求)。选型只用 src+val 池; id/ood 池按规则只在有候选胜过基线时才各评一次。

## 0. 结论
- **没有候选在 src+val 上胜过默认配方,所以没有去评 id / ood,也没有改任何 agent 可见内容**(没有新增 scilib 工具,没有改 `docs/tasks/FoR34.md`)。
- src+val(2880 个分子、57 个正例)上、4 次训练采样的平均 ROC-AUC [实测]: 默认配方 `scilib.molecules.fit_predict` **0.8195**; 用 CheMeleon 指纹的各种做法 0.69–0.81, 最好的是"默认特征与 CheMeleon 指纹拼接后训练同一个树集成" 0.8066, 以及"默认配方与它的等权秩平均" 0.8157。都不高于基线。
- 与同行对照(`reports/overnight_20260930.md` §11)的判定不变: **CONSISTENT**(我们合并 AUC 0.8025 对 OGB 榜上 RF 指纹 0.806–0.821)。预训练分子表示在公开文献里也常常不优于 ECFP 加 RF 基线(检索结果, 未逐篇核实 [估计])。这次的实测与之一致。

## 1. 工具与权重
- CheMeleon(Burns 等, 2025): 以 PubChem 分子的 Mordred 描述符为监督目标预训练的 D-MPNN(6 层隐藏维 2048), MIT 许可。权重 `chemeleon_mp.pt`(Zenodo 10.5281/zenodo.15460715, 34,859,448 B)。
  - md5 `6a80b54fdb7de37ef0374d302f01e8ce`(与 Zenodo 登记一致); sha256 `c376624d3407204e780a0ed13a9ac097cc9bb1c13ef89cdbc633c1715c183651`。位置 `$S/models/mol/chemeleon/`。
  - Node0015 直连 Zenodo 约 12 KB/s(300 秒只下了 3.5 MB), 改在 VPS 上下载再拉取。
- 指纹代码: 照官方 `chemeleon_fingerprint.py`(chemprop ≥ 2.2: `BondMessagePassing` + `MeanAggregation` + `SimpleMoleculeMolGraphFeaturizer`)。服务器环境 `$S/env` 新装了 `rdkit` 与 `chemprop 2.3.1`(清华镜像)。全部 41,127 个 SMILES 在 GPU 5 上 24 秒算完, 无解析失败 [实测]。输出 2048 维。
- 未试: ChemBERTa-77M、MolFormer-XL、Uni-Mol 等其他预训练表示。原因: 检索到的对比文献里它们同样不优于 ECFP 加 RF [估计], 而 CheMeleon 在其论文的 Polaris 与 MoleculeACE 基准上报告了较高的胜率 [估计: 来自检索摘要, 未核实]; 在 CheMeleon 都没有收益的情况下继续堆候选只会增加选择度。

## 2. 实验(只用 src + val 池) [实测]
- 数据与池: 与适配器完全相同的池(src 2263/45 个正例, val 617/12, id 1233/24, ood 4113/130), 训练集用适配器自己的 `_train_sample` 做 4 次 4000 个分子的标签分层采样(每次 150 个正例), 与 episode 里 `load_train` 同分布。id、ood 在这一步没有被特征化也没有被评分。
- 每次采样: 默认配方训练 + 各候选训练, 在 src+val 合并池上算 ROC-AUC, 再对 4 次取平均(`scripts/f34/exp_sv.log`):

| 方法 | 平均 AUC | 4 次采样 |
|---|---|---|
| 默认配方 `fit_predict`(RF+ET, 4480 维指纹/描述符) | **0.8195** | 0.837 / 0.802 / 0.802 / 0.838 |
| CheMeleon 指纹 + 逻辑回归 C=0.01 | 0.7136 | 0.760 / 0.608 / 0.742 / 0.745 |
| 同上 C=0.1 / C=1.0 | 0.6926 / 0.6787 | |
| CheMeleon 指纹 + ExtraTrees(500) | 0.7910 | 0.806 / 0.753 / 0.788 / 0.818 |
| 默认特征 ∥ 指纹 → 同一个树集成 | 0.8066 | 0.812 / 0.796 / 0.812 / 0.807 |
| 默认配方与逻辑回归(C=0.01)等权秩平均 | 0.7817 | |
| 默认配方与 ExtraTrees 指纹等权秩平均 | 0.8102 | |
| 默认配方与"拼接"模型等权秩平均 | 0.8157 | 0.827 / 0.801 / 0.809 / 0.826 |

- 解读: 冻结的 CheMeleon 指纹本身(0.79)弱于指纹加描述符的树集成(0.82), 与默认配方混合也只是接近而不超过它。区别在 4 次采样之间波动 ±0.02 的量级, 正例只有 57 个, 所以这是"没有证据显示更好", 不是"证明更差"。
- 没有做的事: 没有对这些候选在 id / ood 上评分; 没有调逻辑回归之外的超参; 没有做微调(不自己训练)。

## 3. 披露与局限
- 预训练数据重叠: CheMeleon 在 PubChem 分子(及其 Mordred 描述符)上预训练, 没有用 HIV 的活性标签。PubChem 与 ogbg-molhiv 的分子可能有重叠(结构层面), 未核查。
- 选择度: 10 个候选(3 个逻辑回归、1 个嵌入上的 ExtraTrees、1 个拼接、5 个与默认配方的等权秩平均)里没有一个胜过基线, 因此没有被选中的, 所以没有选择偏差需要披露。
- 统计功效低: src+val 只有 57 个正例, 4 次采样来自同一训练分区, 区别小于 0.02 的差异测不出来; 因此不能排除"嵌入有 0.01–0.02 的真实小增益"。
- 网关仍是 HTTP 502, 没有跑 agent 端到端 episode; 验收规则(AUC ≥ 参考 + 0.05, 每 episode 仅 4 个正例)本身的噪声也使"单 episode 通过"几乎不受这类小增益影响, 见 `docs/tasks/FoR34.md` 的噪声分析。
