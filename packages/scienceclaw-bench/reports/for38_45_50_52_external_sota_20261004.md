# FoR38/FoR45/FoR50/FoR52 external SOTA and route audit (2026-10-04)

This is a read-only route audit. It does not change a scorer, acceptance rule, split, item allocation, or any formal result.

## FoR38: Chronos-Bolt check

The staged official Chronos-Bolt-base checkpoint (`amazon/chronos-bolt-base`, exposed as
`scilib.tsfm` model `chronos_bolt`) was run on the complete trusted-side pools using only
history at the 2021 origin.  The same physical caps and sMAPE implementation as the adapter
were applied after inference.

| split | n | Chronos-Bolt mean sMAPE | fixed macro route |
|---|---:|---:|---:|
| ID | 64 | 16.45184 | 13.6593 |
| OOD | 141 | 10.75699 | 10.2101 |

Chronos-Bolt is therefore weaker on both complete pools.  It is not registered as a new
policy alias and no formal item is repeated.  The existing equal-weight macro route remains
the reproducible route.  The probe used the already staged checkpoint under
`models/tsfm/chronos_bolt_base`; no target values entered the predictor.

## FoR45: official shared-task systems found, but no deployable frozen route

The official AmericasNLP 2026 repository publishes a baseline and permits external resources.
The strongest public implementation located in this audit is the UF Gators submission
(`dhawan98/AmericasNLP2026-Gators-Submission`).  Its reported system is a two-stage
Qwen2.5-VL Spanish caption followed by Gemini 2.5 Flash retrieval-augmented translation,
with language-specific parallel corpora and synthetic exemplars.  The public paper reports
large dev/test gains for Bribri, Guarani, and Orizaba Nahuatl.

This is useful SOTA evidence but is not a frozen, self-contained component that can be
added to the current tool pool: it requires a separate multimodal checkpoint/API and
external translation corpora; no approved local checkpoint or Gemini credentials are
present in this checkout.  The public Aya Vision 32B adapter is also only a 395 MB PEFT
adapter and requires the gated `CohereLabs/aya-vision-32b` base; it covers four languages
and is not a complete local inference artifact.  We therefore do not add a route that
would silently fall back to the existing Qwen text endpoint or image-blind captions.
The existing CLIP route remains a visible-data diagnostic only and its previous 8-item
engineering results are unchanged.

## FoR50: exclusion of the apparent SemEval winner checkpoint

The public `tum-nlp/Deberta_Human_Value_Detector` model card states that the model was
“trained and tested on a dataset of 9324 annotated arguments” and reports the SemEval-2023
F1 of 0.55.  The local ValueEval deposit has exactly the same 9324-argument universe:

- `arguments-training.tsv`: 5,393
- `arguments-validation.tsv`: 1,896
- `arguments-test.tsv`: 1,576 (the current ID pool)
- `arguments-test-nahjalbalagha.tsv`: 279 (the current OOD pool)
- `arguments-validation-zhihu.tsv`: 100
- `labels-test-nyt.tsv`: 80 labels (the NYT text is not in this deposit)

The total is 9,324.  Consequently, the checkpoint's advertised training/test universe
includes the current ID and OOD argument labels.  It is excluded from the tool pool under
the no-label-leakage rule, even though it is a strong published reference.  The existing
visible-data `scilib.valueeval.fit_predict` route and full-pool diagnostics remain the
only eligible routes.

Source: <https://huggingface.co/tum-nlp/Deberta_Human_Value_Detector>

## FoR52: no eligible same-metric public checkpoint found

The public literature and model searches found no independently trained checkpoint whose
input/output contract matches the local Psych-201 discrete-choice task and whose metric is
the local micro accuracy.  The cited language-model results use NLL or different task
protocols, and the available Psych-201 data are already the visible training/evaluation
universe.  The fixed and adaptive `scilib.psych` routes remain label-free and deterministic;
no new frozen route or duplicate formal item is introduced.

## Decision

No safe external route found in this pass improves FoR38 or can be deployed for FoR45 under
the current credentials/weights.  FoR50's strongest apparent checkpoint is disqualified by
full-universe overlap, and FoR52 has no same-metric independent checkpoint.  Existing route
boundaries and formal results are retained.
