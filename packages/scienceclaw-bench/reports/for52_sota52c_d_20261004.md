# FoR52 SOTA52C/D formal tool audit — 2026-10-04

This note records the two disjoint follow-up batches for the domain-adaptive
Psych route. It does not change the scorer, acceptance margin, split seed, or
the one-evaluation-per-item rule.

## SOTA52C: OOD 16–19, invalid for the requested route

The original `SOTA52C` request declared `psych_domain_adaptive_predict`, but
the four completed trajectories called `psych_fixed_predict` instead. The
results are therefore not formal evidence for the adaptive tool. Their raw
primary values were `0.6250, 0.5625, 0.4375, 0.6875` (mean **0.578125**);
all four were completed, hard-valid, reproducible, and within budget, but all
had `z=0`. No ID result was produced: the ID pool supports only 16 episodes,
so the requested `skip=16` suffix was empty and the adapter emitted a
short-pool warning. These items are not rerun.

The manifest is now OOD-only for `SOTA52C`; its undeclared ID split makes any
future accidental ID launch fail at preflight.
