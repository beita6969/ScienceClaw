Trajectory FoR40-id-77545a09-00: 6 steps, load_train, load_eval, `scilib.anomsound.component_scores` + `rank_average`; official 0.461 (AUC-src 0.516, AUC-tgt 0.406, pAUC 0.474) vs ref 0.401. **Verdict: CONSISTENT.** Ours 0.461 / 0.604 / 0.610 (mean 0.56, single machine each) sit on the published baseline level for the same dev machines (0.46-0.69 per machine, 55 macro) despite 40x less training data; nowhere near the 66-67 of top teams (which is expected: no ML training, 16 clips).

**Comparability: not directly.** Challenge = models trained on ~40k stays, scored on hidden stays with real-time (hour-by-hour) causal API; ours = whole stays given, causality enforced by a truncation probe, 16 stays with exactly 2 septic (12.5 %), agent trains on only 524 A stays (30 septic!), OOD = hospital B (8 septic) unseen in training. **Parity: exact.** `compute_prediction_utility_official` and the vectorized `prediction_utility` (for42_sepsis.py:98-155) vs the unchanged official file in the local dataset (evaluator/upstream/evaluate_sepsis_score.py): max |diff| = 0 on 3000 random stays (lengths 1-119, septic onset anywhere); best-predictions window `[t_sepsis+dt_early, t_sepsis+dt_late+1)` (:157-165) and (obs-inaction)/(best-inaction) summed over stays (:174-181) match official lines 143 and 156.
**Leakage audit.** Records end 8-10 h after first positive label in the public data, so "flag the last 12 h" gets NU 0.68-0.71 on our pools (my check) - about 2x the challenge winner. The guard (not_positional_only + causal_prefix truncation probe, :184-236, ACCEPT_FLOOR at :86) is active: all 5 runs show causal_prefix 0/391..0/466 changed hours. Agent code in all 4 inspected runs is a single call `scilib.sepsis.fit_predict(train, [eval])` with defaults; FoR42-id-e01 outputs zero alarms (NU exactly 0.0, ref -0.13), val-e00 fires 10 alarms (NU -0.02 vs ref 0.51).
**Verdict: CONSISTENT** (episode NU -0.02...0.57, mean 0.23, inside the +-0.30 noise band; below the 0.36-0.43 published range as expected from ~1 % of the training data; nothing suspiciously high).
**To-do:** (1) report pooled NU over >= 64 stays instead of per-16-stay episodes (for42_sepsis.py:455 already pools; use it for the headline); (2) note in the paper that 12.5 % prevalence inflates NU ~40 % (:477 `k_pos = max(1, round(k*0.125))`); (3) consider min 3 septic per episode to cut SD; (4) keep the record-end probe - removing it re-opens a 0.7 NU shortcut.

**Published numbers** (Dorie, Hill, Shalit, Scott, Cervone, Stat. Sci. 34(1):43-68, 2019, arXiv 1707.02641; 77 settings x 100 replications = 7,700 black-box datasets, estimand SATT, bias/RMSE in sd-of-outcome units)

| BART / ps-BART / BCF (7,700 datasets) | roughly 0.02 / 0.01 / 0.01 (rounded, from bias -0.0016(SD .02), -0.0011(.01), -0.0009(.01)); mean abs bias 0.012 / 0.010 / 0.008 | Hahn, Murray, Carvalho, Bayesian Analysis 15(3):965 (2020), Table 4; RMSE = my sqrt(bias^2+SD^2) |
| Causal RF (grf) | approx 0.043 (bias -0.0155, SD .04) | same |
| bart_on_pscore / bart_tmle / mbart_symint | 0.014 / 0.016 / 0.017 | search-result snippet of the Dorie table, not verified in the PDF |

PEHE (sd units): BART 0.36, ps-BART 0.34, BCF 0.33. Neural-net papers on ACIC 2016 report unnormalised numbers: not found in standardised form. Ours: id 0.0313 (ref OLS 0.1379), 0.0241 (0.1422); val 0.0209 (0.1255); frozen replays 0.0271/0.0175 and 0.0321/0.0227.
**Comparability: roughly (same DGP, estimand and normalisation; different realisations).** Local data = 192 datasets regenerated with the unmodified official generator (aciccomp2016 282d2665), 19 held-out settings for id/val; adapter uses SATT = mean_{z=1}(mu1-mu0) (paper footnote 12 definition) and RMSE / sd(y), the paper's standardisation. Sanity: the local sd(y) is 5.5 and SATT 3.7 (0.68 sd); unnormalised errors are 5.5x larger, so 0.17 must never be set beside published standardised values. Local OLS (linear model) = 0.11-0.14 in sd units, same magnitude as the paper's linear-model baseline. Noise: bootstrap of the agent's 48 per-dataset errors gives a 16-dataset RMSE of 0.025 +- 0.006 (p5-p95 0.016-0.035); OLS slice 0.14 +- 0.016. Episode OLS refs (0.1379, 0.1422, 0.1255) equal the pool values (id 0.142, val 0.123): slices are representative.
