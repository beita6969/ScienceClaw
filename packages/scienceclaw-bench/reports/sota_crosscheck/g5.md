**Comparability: NOT directly comparable, biased upward.** Published = one F1 over all 1576 (or 279) items. Ours = F1 over 16 items where `official_f1` skips every value with no gold positive (for50_valueeval.py:78-80), so false positives on absent values are free and rare values drop out. A 2-episode pool (32 items) still carries +0.03-0.04 and sd 0.05. The agent also picks per-value counts with `expected_f1_decision` (scilib/valueeval.py:173), which maximises exactly this slice metric, so its bias is at least the model-independent +0.04-0.06.
**Parity: MATCH.** `official_f1` (for50_valueeval.py:66-91) is the official formula: per-value P and R over values with gold support, P=0 when nothing is predicted, F1 = 2PR/(P+R) of the macro means (not the mean of per-value F1s, which is kept separately as `mean_category_f1`). My re-implementation of the official evaluator gives the published 1-baseline numbers on all three test sets. `pooled_metric` (:202) concatenates items across episodes, which is right.
**Leakage audit: clean.** Train/eval conclusion, premise and (conclusion, premise) overlap is 0.000 for val, test and Nahj (checked exactly on the raw TSVs); `_build` additionally drops train rows whose text is in any eval pool (:142-143); src/val are split by conclusion group (:138, VAL_FRACTIONS). Paraphrase near-duplicates not checked. Labels are only in the eval payload. Easy path: the trivial "all 20" reference already scores 0.32-0.36 (id) / 0.22 (ood) per slice, so the 0.05 margin (:28) is only 0.7 slice-sd.
**Verdict: NOT-COMPARABLE as reported; debiased level CONSISTENT.** Subtracting the simulated slice bias (+0.04 to +0.06) puts the agent at about 0.45-0.47 on Main (above BERT 0.42, below the 0.56 winner and below the 0.53-0.57 that third parties report for GPT-4o-class prompting) and about 0.29-0.33 on Nahj (BERT 0.28, winner 0.40). Nothing suggests a bug or leak; there is no BELOW-PEERS signal either.
**To-do.** (1) Never quote slice F1 next to the 0.56/0.40 leaderboard; add a full-test evaluation of the agent's pipeline (1576 + 279 items) or report `ref_full - ref_slice` as the bias. (2) Pool at least 8 episodes (128 items) before comparing and report the reference on the same pool (pooled_metric, :202). (3) Report per-value F1 and n_scored_categories in the summary (already in eval details, :352). (4) Consider a fixed-support variant that scores all 20 values with the full-test prevalence. (5) Raise the acceptance margin or test on pooled data: 0.05 (:28, :176) is below one slice sd (0.07).

Off-leaderboard: JMP-L 20.57 (fold0 21.28), JMP-S 22.77 (arXiv 2310.16802 Tab.4, paper-reported 5-fold mean). Nothing newer found on the board; 2025 foundation-model papers I opened (MatterTune 2504.10655, Nequix 2508.16067) do not report matbench_phonons.
**Ours** (16-item slices): id 28.26 / 52.90 (ref 5-NN 203.4 / 77.1), ood 26.90 / 27.50 (ref 60.2 / 48.0), val 53.06 (ref 101.8).
**Comparability: id roughly, ood NOT.** Matbench trains on about 1012 structures with random folds; ours is one stratified random split (train 676, dev 110, src 161, val 40, id 99; for51_matbench.py:52, :249-257) with the agent's GBM on 35 hand features. I reproduced the split and the agent's GBM exactly (identical in all FoR51 runs): pool MAE dev 50.7, src 39.2, val 48.2, id 40.1, ood 30.4. Random 16-slice 5-95%: id 26-57 (median 39), ood 19-45 (median 29), dev 25-97 (heavy tail). All four reported episode scores lie inside those bands (28.3 is at about p10, 52.9 at about p88), so they are draws, not evidence of level. Relative to the full-data MAD (323.8 = Dummy): SOTA 0.089, JMP-L 0.064, agent id 0.124, dev 0.157. The ood pool (Se/Te compounds, `OOD_ELEMENTS` :51) has a compressed target range (mean 286, MAD 110), so its MAE 30 is only 0.275 of its own MAD: "OOD at or below SOTA" is a scale artefact.
**Parity: MATCH.** `pooled_metric` (:233-246) is plain MAE in cm^-1 on raw targets, direction min, equal to matbench's `mae` (fold MAEs of equal-size folds average to the pooled MAE). No transform, clipping or unit conversion. Invalid output is scored with the reference predictions (:242), which is lenient compared with FoR52's all-wrong rule.
**Leakage audit: clean.** No exact duplicate structures or targets between train and id/ood; 11% of id items share a reduced formula with a train item (polymorph/sibling structures), the same property as Matbench's own random CV. `y_true` only appears in the eval payload. Easy-path check: composition-only features give MAE 69-136, i.e. the structural descriptors (volume/atom, density, packing, nearest-neighbour distance) carry the signal, as for RF-SCM/Magpie 67.6 vs structure models 29-39 on the board. The ood pool is easier by scale only.
**Verdict: CONSISTENT (id); ood absolute score NOT-COMPARABLE.** True id level about 40 (dev 50.7, val 48) vs SOTA 28.8: about 1.4x worse, in the MODNet/SchNet/DimeNet++ tier (34-39) to Finder (47) and far better than composition-only 68; expected for 676 vs 1012 training structures and a feature GBM. Missing component vs SOTA: structure-aware GNN or pretrained model and the extra 300 training samples.
**To-do.** (1) Report MAE / MAD (or MAE / dummy-MAE of the same pool) next to MAE; never compare ood MAE with 28.8 (add to `pooled_metric` :233 and eval details). (2) Pool at least 8 episodes for any leaderboard comparison (slice sd about 10 cm^-1). (3) The 5-NN reference (`_fit_reference` :259, `_ref_predict` :267) is 2-7x worse than GBM on some slices (203 on ep00) and inflates `norm_score` (7.2); add a GBM/composition-only reference or clip norm_score. (4) Document that 11% id/train formula siblings are by design (`_partition` :249, no group split). (5) For a peer number, give the pipeline all 1012-sample-equivalent training data or note the 33% smaller train set.

## FoR52 - Psych-201 discrete choices (micro accuracy of predicting a held-out human choice)
**Published numbers** (the literature reports NLL on held-out participants, essentially never accuracy)
| source | quantity | value |
|---|---|---|
| Centaur (Binz et al., arXiv 2411.10109; Nature 2025), Psych-101 held-out participants | avg NLL per response | Centaur 0.44; base Llama-3.1-70B 0.58; domain cognitive models 0.56 |
| Same, held-out settings (modified two-step, 3-armed bandit, logic items) | NLL | Centaur 0.51 / 0.42 / 1.65 vs Llama 0.63 / 0.62 / 1.92 |
| Same, economic-games social-prediction study | accuracy | 64% human targets, 35% artificial targets (Centaur simulating a predictor): NOT next-choice accuracy |
| Binz et al. 2026, Psych-201 (arXiv 2605.07632, Fig. 2 and S2) | NLL / accuracy of 0-shot LLM families | best NLL 1.557 (Qwen2.5-72B); accuracy on a discrete-choice subset spans about 0.55-0.70 (read off Fig. S2 axis, no table) |
| Oh and Gobet, COLM 2026 (arXiv 2608.05224) | NLL of small fine-tuned models; prompt ablation | history-only retention is below chance on average over 27 tasks; instructions removal costs little |
Pseudo-R2 figures of the Nature version: seen only as search snippets, unverified. Xie and Zhu 2025 / Liu and Ding 2025 (choice-history and instruction ablations) are known to me only via Oh and Gobet. No accuracy leaderboard exists: **no directly comparable published accuracy was found.**
**Ours** (16-item episodes, accuracy): id 0.750 / 0.750 / 0.6875 / 0.750 (refs 0.625-0.6875); ood 0.6875 / 0.625 (refs 0.5625 / 0.4375); val 0.5625 (ref 0.6875, z=0).
**Comparability: NOT-COMPARABLE with NLL results; only roughly with Fig. S2.** Ours: 36 studies, strict single-key parsing, one hash-chosen marker per session (per-session weighting, `_episode` :414), teacher-forced history, tools plus optional LLM answers. Papers: all responses of held-out participants, NLL. The SE of a 16-item accuracy is 0.12 (0.085 for 32 items), so 0.5625 vs 0.75 is noise-level. My no-LLM pool run of the environment toolkit (32 train sessions, `psych.fit_predict`, scilib/psych.py:742) on the whole pools (id 263 sessions, ood 544): last-response 0.563 / 0.601, most-frequent 0.529 / 0.607, kernel 0.620 / 0.647, q-learn 0.635 / 0.631, WSLS 0.624 / 0.623, GBDT 0.608 / 0.651, auto-mix 0.631 / 0.647. The agent's slice means (id 0.734 = 4 runs on the same 2 episodes, 32 distinct items; ood 0.656 over 32 items) are +1.2 SE above and equal to that, i.e. any LLM gain is small or lucky. The band 0.55-0.70 of Fig. S2 brackets these, but on different studies.
**Parity: MATCH for its own definition.** `pooled_metric` (:380-393) is micro accuracy over all items; invalid output counts as wrong. There is no official accuracy definition to compare with; the papers' NLL/pseudo-R2 need probabilities, which the harness does not collect (accuracy ignores calibration; see Fig. S2 of Binz 2026, where accuracy and NLL rank models differently).
**Leakage audit.** Eval sessions come from the public Psych-201-discrete training split, i.e. the Centaur/Psych-201 population; only about 3% are flagged `in_eval`/`is_psych101_test` (excluded from visible data, :199-208, :316). For a frozen agent this is not label leakage in the harness, but the base Qwen3.8 may have seen Psych-101 (public since 2024): unverifiable. Choice history is a strong shortcut (persistence 0.56-0.61 vs 0.53-0.61 for the mode), and the reference `reference_prediction` (:169) is mode-with-recency-tie-break, weaker than 'last response' on id; a raw slice ref is 0.44-0.69, so z is dominated by noise.
**Verdict: CONSISTENT (no bug signal), but NOT-COMPARABLE with published NLL results.** Pool-level toolkit accuracy 0.63-0.65 and agent slices 0.63-0.73 are inside the published zero-shot band 0.55-0.70 (Fig. S2) and not suspiciously high; the val failure (0.5625 vs ref 0.6875) is within one SE. A 48-item dev set (N_DEV_ITEMS :71) is too small to choose among methods (dev 0.6875 -> val 0.5625).
**To-do.** (1) Collect a probability vector per item and report NLL / pseudo-R2 (per-response weighting) next to accuracy so Fig. S2-style and Centaur-style comparisons exist (evaluate() :482-498). (2) Strengthen the reference to max(most-frequent, last response) or report both (reference_prediction :169). (3) Pool at least 8 distinct episodes (128 items, SE 0.04) before z; the 0.05 margin (ACCEPT_MARGIN :73) is 0.4 slice-SE. (4) Report per-study accuracy; the 36-study subset with per-session weighting differs from the papers' per-response averages. (5) Check base-model contamination with a Psych-101 prefix-completion probe if the paper claims generalisation.
